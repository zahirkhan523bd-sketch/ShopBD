# ShopBD — Electronics & Gadgets

বাংলা-ভিত্তিক responsive e-commerce storefront starter built with plain HTML, CSS and JavaScript.

## চালানোর নিয়ম
1. ZIP ফাইলটি Extract করুন।
2. `index.html` ফাইলটি Chrome/Firefox-এ খুলুন।
3. কোনো build tool বা framework প্রয়োজন নেই।

## এই ডেমোতে আছে
- Responsive homepage (desktop/mobile)
- Black & Gold visual theme
- Product cards and category filtering
- Product search
- Cart drawer with quantity controls
- Wishlist
- Cart/Wishlist data saved in LocalStorage

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এটি frontend demo। বাস্তব অর্ডার, user login, inventory sync, admin panel, payment gateway, delivery tracking বা server-side database এখনো যুক্ত নয়। এগুলোর জন্য backend/API এবং নিরাপদ payment integration প্রয়োজন হবে।
Product images are loaded from Unsplash, so internet connection is required for those images.
